# REPRODUCE

Paper: A. Sunol et al., *Learning constitutive models and rheology from partial flow measurements*,
[arXiv:2510.24673](https://arxiv.org/abs/2510.24673).

One row per paper figure and table, in the paper's numbering. The internal run tag is given in parentheses
where it differs; the original campaign names are recorded in each bundle folder's `PROVENANCE.txt`.

The "expected artifact" column gives two things: the **bundle** path, which is what a stranger can compare
against without rerunning anything, and the **fresh run** path under `work/`, which is where the command
writes when you do rerun it. Run subdirectory names keep the original run identifiers, because those are
also the target ids used by the model-selection battery.

Two figure pipelines produce the paper. The `paper_figs` package generates the viscoelastic and
elastoviscoplastic figures (Figs. 5–6, S7–S15) directly from the deposited bundle. The instantaneous
figures (Figs. 2–4, S1–S6) are generated by the notebooks in `notebooks/`, reading the same bundle.
Figures 4a and 7, Supplementary Figures S16–S20, and the bulk-rheometry tables come from `diff_rheo`.

Environments: `cfd` = `cfd_md_optimization` (`environment.yml`, referred to below as `$PY`); `diff_rheo` =
`environment_diff_rheo.yml` (`$PYDR`, needs diffrax). Partition and wall times are the recorded production
values, not re-timed here.

## Verification

`python verify/run.py --level quick` needs nothing but a clone and the solver environment: it checks that
the vendored packages resolve, that the paper loss mask rebuilds to its recorded hash, that the duplicated
closure definition still matches the library, and that the three examples run.

`--level full` adds the checks that need data or hardware. Each one skips with a one-line message when
what it needs is absent, so the suite is runnable anywhere; these variables turn the skips into runs:

| variable | needed by | what it names |
|---|---|---|
| `DATA_ROOT` | `figure_parity`, `bundle_parity`, `battery` | the unpacked Zenodo deposit |
| `TBNN_PYDR` | `battery` | a Python from `environment_diff_rheo.yml` |
| `TBNN_FROZEN_MEM` | `learned_forward`, `cavity` (full mode) | a local archive of the original viscoelastic runs |
| `TBNN_PY` | batch jobs | the solver-environment Python (default: the running interpreter) |
| `TBNN_CONDA_HOOK`, `TBNN_CONDA_ENV` | batch jobs | conda hook and environment name to activate in a job |

The GPU checks (`gnf`, `evp`, `contraction`, `piv`, `porous`, `obstacle`, `cavity`) run through two batch
jobs when a scheduler is present, and skip when there is no GPU. Values must match
`verify/expected.json`:

```
$PY verify/run.py --level full
```
